# Kelly kriteriyası

Uğur ehtimalı və risk/mükafat nisbətinə əsasən optimal mövqe ölçüsünü hesablayan riyazi düstur.

`f = (bp − q) / b` (b — mükafat/risk nisbəti, p — uğur ehtimalı, q = 1−p)

- Tam Kelly çox aqressiv volatillik yaradır; praktikada çox vaxt "yarım Kelly" istifadə olunur.
- Ehtimalları düzgün qiymətləndirmək çətindir — səhv giriş formulanı mənasız edir.
