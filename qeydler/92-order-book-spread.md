# Order book və bid-ask spread

Order book — bazarda aktiv alış (bid) və satış (ask) əmrlərinin siyahısıdır.

- **Spread** — ən yüksək bid ilə ən aşağı ask arasındakı fərq; likvidliyin göstəricisidir.
- Dar spread = yüksək likvidlik, aşağı əməliyyat xərci. Geniş spread = aşağı likvidlik, hər əməliyyatda gizli xərc.
