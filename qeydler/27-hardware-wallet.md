# Hardware wallet

Private key-i internetə qoşulmayan ayrıca cihazda saxlayır; tranzaksiya cihazın içində imzalanır.

- Yalnız istehsalçının rəsmi saytından alınmalıdır (ikinci əl və ya marketplace riskli).
- Qutudan əvvəlcədən yazılmış seed phrase çıxırsa — cihaz saxtadır.
- Ünvanı və məbləği kompüter ekranında deyil, **cihazın öz ekranında** yoxla.
