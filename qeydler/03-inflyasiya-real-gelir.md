# İnflyasiya və real gəlir

Nominal gəlir — hesabda görünən faizdir. Real gəlir — inflyasiyadan sonra qalan artımdır.

Təxmini: `real gəlir ≈ nominal gəlir − inflyasiya`
Dəqiq: `(1 + nominal) / (1 + inflyasiya) − 1`

Nümunə: depozit 9%, inflyasiya 6% → real gəlir ~2.8%. Depozit 5%, inflyasiya 7% → pul real olaraq əriyir.
