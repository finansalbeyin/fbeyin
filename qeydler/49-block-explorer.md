# Blok explorer-dən istifadə

Etherscan, Arbiscan, BscScan kimi explorer-lər zəncirdəki hər şeyi göstərir.

- **Tx hash** ilə tranzaksiyanın statusunu (Success / Failed / Pending) yoxla.
- Token kontraktının "verified" olub-olmadığına, sahiblərin (holders) bölgüsünə bax.
- Kiminsə "göndərdim" iddiasını yalnız explorer-də təsdiqlə — ekran şəklinə yox.
