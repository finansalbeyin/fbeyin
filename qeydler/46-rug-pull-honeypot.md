# Rug pull və honeypot tokenlər

- **Rug pull**: layihə sahibləri likvidliyi çəkib və ya tokenləri satıb yox olur.
- **Honeypot**: kontrakt almağa icazə verir, satmağa yox (və ya satışa 99% vergi qoyur).

Əlamətlər: likvidliyin kilidlənməməsi, tokenlərin bir neçə cüzdanda cəmlənməsi, anonim komanda + qeyri-real vədlər, kontraktın verify edilməməsi.
