# Airdrop fəaliyyətində təhlükəsizlik

- Airdrop və testnet işləri üçün **ayrıca cüzdan** istifadə et; əsas yığım cüzdanını heç bir yeni sayta qoşma.
- Cüzdanda özü-özünə peyda olan naməlum tokenlərlə əlaqə qurma — onları satmağa/claim etməyə çalışmaq çox vaxt tələdir.
- "Claim üçün əvvəlcə ödəniş et" tələbi — fırıldaqdır.
- Tapşırıq platformalarına verdiyin icazələri (X, Discord, GitHub OAuth) vaxtaşırı yoxla və lazımsızları ləğv et.
