# Kiçik test tranzaksiyası

Böyük məbləği yeni ünvana, yeni şəbəkəyə və ya birjaya göndərməzdən əvvəl kiçik məbləğlə test et.

- Şəbəkənin düzgün seçildiyini (məsələn, ERC-20 və BEP-20 fərqi) yoxla.
- Birjaya göndərərkən memo/tag tələb olunursa, onsuz göndərilən vəsait itə bilər.
- Test xərci kiçik gas haqqıdır; səhvin xərci bütün məbləğdir.
