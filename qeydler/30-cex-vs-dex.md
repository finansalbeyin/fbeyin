# CEX və DEX

- **CEX** (mərkəzləşmiş birja): hesab, KYC, order book, fiat giriş-çıxış. Vəsait birjanın nəzarətindədir.
- **DEX** (mərkəzsiz birja): smart kontrakt üzərində birbaşa cüzdandan ticarət; adətən AMM likvidlik hovuzları.

DEX-də əlavə risklər: saxta token kontraktları, slippage, smart kontrakt xətaları. Token ünvanını həmişə rəsmi mənbədən götür.
